# CubeNova Client mods / CubeNova Client 模組

One folder per Minecraft version / 每個 Minecraft 版本一個資料夾：

| Folder | Minecraft | Java |
|---|---|---|
| `CubeNova-Client-1.20.1` | 1.20.1 | 17 (built with JDK 21) |
| `CubeNova-Client-1.21.1` | 1.21.1 | 21 |
| `CubeNova-Client-1.21.4` | 1.21.4 | 21 |
| `CubeNova-Client-26.2`   | 26.2   | 25 |

Run `build-mod.bat` inside a folder. The jar `cubenova-client-<version>.jar` is copied to `..\..\CubeNova\builtin` (the launcher) and to `jars\` (all built jars together).
在資料夾裡執行 `build-mod.bat`，jar 會複製到啟動器的 `CubeNova\builtin`，也會放一份到 `jars\`。
